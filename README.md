# Graphical Password Authentication System 🔐

## About the Project

The Graphical Password Authentication System is a user authentication project that uses graphical images or patterns instead of traditional text-based passwords.

The system aims to provide a simple and user-friendly approach to authentication.

## Objectives

* To implement graphical password-based authentication.
* To provide an alternative to traditional text passwords.
* To improve user experience during login.
